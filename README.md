# Linux BSP 学习仓库

从零转 Linux BSP / 驱动方向的学习记录。代码、笔记、实验数据都在这里，按 24 周计划推进。

硬件：韦东山 i.MX6ULL（打地基） + 正点原子 RK3568（外设与项目）。

## 目录

| 目录 | 内容 | 阶段 |
|---|---|---|
| `practice/` | 按计划学习之前自己练的，保留原样 | 起点 |
| `docs/` | 学习笔记、bug 记录、实验报告 | 全程 |
| `c-lib/` | 链表、环形缓冲、日志宏等基础库 | W1–4 |

| `patches/` | 对厂商内核 / U-Boot 的改动（patch 序列） | W7 起 |

> `docs/` 以外的目录留到 W3 那周再建，不提前造空架子。

## practice/ 说明

这是按计划学习之前自己写的练习，**保留原始结构，不做整理**，作为起点存档。

- `CTest/` — C 语言：指针、结构体指针、内存对齐、条件编译、多行宏、`__attribute__`、`offsetof`、可变参数函数、综合测试
- `fileio/` — Linux 文件 IO：`open` / `write` / `read`，含中途写入与覆写
- `MakeFileTest/` — Makefile：变量、自动依赖生成、多目录多文件工程

编译产物（`*.o`、`*.d`、无扩展名的可执行文件）已由 `.gitignore` 排除，只在本地磁盘保留。

## 约定

- 每次提交说清「**为什么**改」，`diff` 本身已经说明了改了什么
- 编译产物、压缩包、内核与 SDK 源码不进这个仓库
- 厂商源码放在仓库外面（`bsp-vendor/`），自己的改动以 patch 形式存进 `patches/`
- 每完成一条淘汰线打一个 tag：`w04-passed`、`w10-passed` …
